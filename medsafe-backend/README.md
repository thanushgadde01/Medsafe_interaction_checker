# MedSafe AI Inference API

FastAPI service for the MedSafe drug–food interaction prototype. It encodes two molecular SMILES strings and clinical text, concatenates their pooled Transformer representations, and classifies the combined vector into `Major`, `Moderate`, or `Safe`.

> **Research/demo use only.** This model is not validated for clinical decision-making. Never use its predictions as a substitute for professional medical advice.

## How inference works

1. `MoLFormer-XL` encodes the drug SMILES.
2. The same `MoLFormer-XL` encoder encodes the food SMILES.
3. `PubMedBERT` encodes the clinical text.
4. The three 768-dimensional `pooler_output` vectors are concatenated into 2,304 features.
5. A trained MLP predicts one of three classes.

```text
2304 → Linear(1024) → BatchNorm → LeakyReLU → Dropout(0.4)
     → Linear(256)  → BatchNorm → LeakyReLU → Dropout(0.3)
     → Linear(3) → Softmax
```

The model weights are in `medsafe_optimized_model.pth`. Encoders are loaded from Hugging Face:

- `ibm/MoLFormer-XL-both-10pct`
- `microsoft/BiomedNLP-PubMedBERT-base-uncased-abstract-fulltext`

## Requirements and startup

Python 3.10 or 3.11 is recommended for the pinned PyTorch version. Run from this directory; the checkpoint is loaded relative to the working directory.

```bash
python -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows PowerShell
# .\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8001
```

The first startup downloads both pretrained Transformer encoders and can take time. Inference uses CUDA when available; otherwise it runs on CPU.

## Endpoint: `POST /api/predict`

### Request body

```json
{
  "drug_smiles": "CC(=O)NC1=CC=C(O)C=C1",
  "food_smiles": "C1=CC(=C(C=C1)O)O",
  "clinical_text": "Example clinical context"
}
```

`clinical_text` defaults to an empty string. Both SMILES fields are required by the request schema.

### Example response

```json
{
  "status": "success",
  "source": "ml",
  "prediction": {
    "severity_score": 2,
    "severity_label": "Safe",
    "confidence": "71.56%",
    "raw_probabilities": {
      "Major": 0.1702,
      "Moderate": 0.1142,
      "Safe": 0.7156
    }
  }
}
```

This response is illustrative and does not represent a validated interaction assessment.

### Test with curl

```bash
curl -X POST "http://127.0.0.1:8001/api/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "drug_smiles": "CC(=O)NC1=CC=C(O)C=C1",
    "food_smiles": "C1=CC(=C(C=C1)O)O",
    "clinical_text": "Example clinical context"
  }'
```

## Frontend integration

The frontend API client uses `NEXT_PUBLIC_API_URL` as the base URL and appends `/api/predict`. Its default is:

```dotenv
NEXT_PUBLIC_API_URL=http://127.0.0.1:8001
```

The current frontend name-to-SMILES dictionaries and clinical text are mock implementations. The API accepts SMILES and text directly; it does not retrieve or validate them.

## Operational and safety notes

- The backend currently configures CORS to allow all origins. Restrict this before deployment.
- The endpoint has no authentication or authorization in the current implementation.
- Model and encoder loading occurs when `main.py` is imported, before the service is ready.
- No benchmark metrics, model provenance report, or clinical validation are included with this API.
- Prediction output is experimental and must not be used for treatment or medication decisions.

See the root [Setup Guide](../SETUP_GUIDE.md) for frontend/backend startup instructions.
